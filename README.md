# Credit Risk & Loan Portfolio Analysis

##  Objective
To analyze loan data and identify high-risk customer segments to support better credit decision-making and minimize default risk.

##  Tools Used
- SQL (PostgreSQL / MySQL)
- Power BI (for dashboard visualization)
- Excel (data preprocessing)

##  Dataset
- Source: Sample financial dataset (30K+ records)
- Contains customer demographics, loan details, and repayment status

##  Key Analysis Performed
- Top 3 Home Ownership Categories by Loan Investment
- Loan Performance and Default Rate Analysis by Income Level
- Total Capital Loss by Loan Term
- Income-Based Risk Profiling and Loan Sizing

##  Key Insights
- Low income correlates with higher default rates.
- 60-month terms drive maximum capital loss.
- Mortgage holders represent the largest loan concentration.
- High charge-offs occur in specific loan durations.

##  Business Recommendations
- Tighten criteria for low-income and long-term loans.
- Cap loan amounts for renters to minimize loss.
- Promote 36-month terms to improve bank liquidity.
- Adjust interest rates based on segment default risk.

##  Files Included
- SQL Queries
- Dataset

##  Outcome
Improved understanding of risk factors affecting loan defaults, enabling data-driven decision-making for credit risk management.
